# 실제 클립보드 검사

`DirectBackendSmoke.cs`는 실제 클립보드를 읽고 고유 검사 항목을 생성하여 고정·해제·삭제를 시험합니다. 기본 검사에는 포함되지 않습니다.

수동으로 실행하기로 한 경우에만 `Build.ps1 -TestSource`와 `-EntryPoint DirectBackendSmoke`로 빌드하십시오. 실행 중 다른 복사 작업은 피하십시오. 검사는 기존 이력을 보존하고 검사 항목을 제거하며 원래 현재 클립보드를 복원하도록 설계되어 있습니다. 새 복사 데이터가 감지되면 덮어쓰지 않습니다.

이 검사로 Win+V 창의 표시·포커스·스크롤 결과까지 검증되지는 않습니다.
